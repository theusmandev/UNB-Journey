# Urdu Novel Bank Portfolio

Founder portfolio and digital ecosystem showcase for Urdu Novel Bank. This single-page application highlights the journey, projects, and community built around Urdu literature.

## Development

To run this project locally, you need Node.js and npm installed.

```sh
# Clone the repository
git clone <this-repository-url>
cd <repository-name>

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Production Build

To build the static output for production:

```sh
npm run build
```

This will generate a `dist` folder containing the compiled HTML, CSS, and JS files, which can be deployed to static hosting providers like GitHub Pages.
